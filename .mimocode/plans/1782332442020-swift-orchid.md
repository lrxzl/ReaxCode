# Plan: 添加可拖拽悬浮按钮切换 WebView/终端

## Context
当前 TermuxActivity 使用"快速点击8次"的方式切换 WebView 和终端视图（`dispatchTouchEvent` 中的 `mTapCount == 8` 逻辑，第 538-558 行）。用户希望替换为一个可拖拽的悬浮按钮，点击即可切换，并移除旧的快速点击机制。

## 修改文件

### 1. 新建 `app/src/main/java/cn/net/xiangxiang/seeker/FloatingToggleButton.java`
- 一个可拖拽的圆形悬浮按钮（类似 FAB）
- 实现拖拽：参考 `FloatingWebView.java` 中的触摸处理模式
- 点击回调接口，用于触发切换
- 尺寸约 48dp，带半透明背景和阴影
- 默认位置：屏幕右下角，距底部/右侧有一定边距
- 支持拖拽到屏幕任意位置
- 用一个简单图标/文字区分当前状态（WebView/终端）

### 2. 修改 `app/src/main/java/com/termux/app/TermuxActivity.java`
- **移除** `dispatchTouchEvent` 覆写（第 538-558 行的快速点击逻辑）
- **移除** `mLastTapTime`、`mTapCount` 字段（第 538-540 行）
- 在 `onCreate()` 中初始化 `FloatingToggleButton`，添加到根视图
- 点击回调调用已有的 `toggleWebViewTerminal()`
- 切换时更新按钮状态图标/文字
- 初始状态：`mStartWithWebView = true`，按钮显示终端图标；切换到终端后按钮显示 WebView 图标

### 3. 修改 `app/src/main/res/layout/activity_termux.xml`
- 在根 `RelativeLayout` 内添加一个 `FrameLayout` 容器（id: `floating_button_container`），用于承载悬浮按钮

## 实现细节

### FloatingToggleButton 设计
```
- 继承 FrameLayout
- 内部一个圆形 ImageView/TextView（48dp）
- 半透明深色背景 + elevation 阴影
- 触摸事件处理拖拽（ACTION_DOWN/MOVE/UP）
- 点击检测：按下和抬起位移 < 10dp 视为点击
- 状态切换时更新图标（终端模式→显示 WebView 图标，WebView 模式→显示终端图标）
```

### TermuxActivity 修改
```java
// onCreate 中添加：
mFloatingToggle = new FloatingToggleButton(this);
mFloatingToggle.setOnClickListener(v -> toggleWebViewTerminal());
// 添加到 frameLayout container

// toggleWebViewTerminal 中增加按钮状态更新：
mFloatingToggle.updateIcon(mIsShowingWebView);
```

## 验证
1. 编译项目：`./gradlew assembleDebug`
2. 功能测试：
   - 启动 app，默认显示 WebView
   - 悬浮按钮可见，可拖拽
   - 点击按钮切换到终端
   - 再次点击切换回 WebView
   - 旧的快速点击不再触发切换
